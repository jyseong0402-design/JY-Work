# 백데이터 저장소

사무자동화(엑셀 작업대, `excel_report.py`)에 쓰는 원본·기준 데이터를 모아두는 곳입니다.

| 폴더 | 넣을 파일 | 예시 |
|---|---|---|
| `raw/` | 주기적으로 받는 원본 데이터 (법인별 폴더) | 계정별원장, 월별 매출, 시스템 다운로드 파일 |
| `master/` | 잘 바뀌지 않는 기준 정보 | 거래처 목록, 품목·단가표, 조직·담당자 목록 |
| `templates/` | 보고서·양식 서식 | 월간 보고 양식, 정산서 양식 |

## 법인별 폴더 (`raw/`)
```
raw/
├─ 대흥_닥터애그/계정별원장/   대흥농산 5개 사업장 + 이천팜·디에이치팜·디에이치아그로·대흥컴퍼니
├─ 송이애/계정별원장/          송이애, 송이애1, 송이애2
└─ 군자농원/계정별원장/        군자농원, (군자)원삼·미평·이천
```
파일별 기간·행 수는 [`raw/계정별원장_목록.md`](raw/계정별원장_목록.md)에 있습니다.

## 파일 이름 규칙
`자료명_법인_기간(YYMM).xlsx` 형식으로 저장합니다. 예: `계정별원장_대흥_2610.xlsx`, `계정별원장_송이애_2601-2608.xlsx`

## 바로 집계하기
```bash
python excel_report.py back-data/raw/송이애/계정별원장 --group 계정명 --value KRW
```

## 주의
- GitHub는 파일 하나당 100MB까지 올릴 수 있습니다.
- 개인정보(주민번호, 연락처 등)가 들어 있는 파일은 저장소를 비공개로 두거나, 해당 열을 지운 뒤 올리세요.
