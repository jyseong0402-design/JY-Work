# 백데이터 저장소

사무자동화(엑셀 작업대, `excel_report.py`)에 쓰는 원본·기준 데이터를 모아두는 곳입니다.

| 폴더 | 넣을 파일 | 예시 |
|---|---|---|
| `raw/` | 주기적으로 받는 원본 데이터 | 월별 매출, 지점별 실적, 시스템 다운로드 파일 |
| `master/` | 잘 바뀌지 않는 기준 정보 | 거래처 목록, 품목·단가표, 조직·담당자 목록 |
| `templates/` | 보고서·양식 서식 | 월간 보고 양식, 정산서 양식 |

## 파일 이름 규칙
`내용_기간.xlsx` 형식으로 저장하면 정렬과 취합이 쉽습니다. 예: `매출_2026-10.xlsx`, `거래처목록_2026.xlsx`

## 바로 집계하기
```bash
python excel_report.py back-data/raw --group 지점 --value 매출액
```

## 주의
- GitHub는 파일 하나당 100MB까지 올릴 수 있습니다.
- 개인정보(주민번호, 연락처 등)가 들어 있는 파일은 저장소를 비공개로 두거나, 해당 열을 지운 뒤 올리세요.
