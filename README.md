# JY-Work · 사무자동화 도구

엑셀 파일을 만들고 분석하는 작업을 줄이기 위한 도구 2가지입니다.

## 1. 엑셀 작업대 (`excel-workbench.html`) — 웹페이지

설치 없이 브라우저로 여는 엑셀 분석 페이지입니다. 파일은 서버로 올라가지 않고 내 PC 브라우저 안에서만 처리됩니다.

**사용법:** `excel-workbench.html`을 더블클릭해 Chrome 또는 Edge로 엽니다. 엑셀 라이브러리를 불러오기 위해 인터넷 연결이 필요합니다.

| 탭 | 하는 일 |
|---|---|
| 데이터 | xlsx·xls·csv 여러 개 열기(끌어다 놓기 가능), 전체 검색, 열 조건 필터(`서울`, `>100`, `<=2026-03-31`), 머리글 클릭 정렬, 중복 행 제거, 공백·빈 행 정리 |
| 열 통계 | 열마다 형식(숫자·날짜·문자), 빈칸 수, 고유값 수, 합계·평균·최소·최대, 가장 많은 값 |
| 피벗 집계 | 행 기준 × 열 기준으로 합계·평균·개수·최대·최소 집계, 합계 행·열, 막대 차트 |
| 파일 합치기 | 같은 양식의 여러 파일·시트를 하나로 이어 붙이기 (열 이름 기준으로 맞춤, ‘원본’ 열 추가) |

**결과 엑셀 저장**을 누르면 `데이터`(필터 적용 결과) · `열통계` · `피벗` 시트가 들어 있는 xlsx 파일이 저장됩니다.

처음 열면 가상의 판매 내역 샘플이 미리 들어 있습니다. 실제 파일을 열면 샘플은 사라집니다.

## 2. 엑셀 보고서 자동화 (`excel_report.py`) — 프로그램

폴더 안의 엑셀·CSV 파일을 모두 합치고, 집계 표를 만든 다음 서식을 입힌 보고서 파일 하나로 저장합니다. 매월 반복하는 취합 작업에 쓰기 좋습니다.

```bash
pip install pandas openpyxl
```

```bash
python excel_report.py 샘플 --sample
```

```bash
python excel_report.py 샘플 --group 지점 --column 품목 --value 매출액
```

| 옵션 | 뜻 |
|---|---|
| `-g, --group` | 행 기준 열 (예: 지점) |
| `-c, --column` | 열 기준 열, 선택 (예: 품목) |
| `-v, --value` | 값 열 (예: 매출액). 빼면 행 개수를 셉니다 |
| `-a, --agg` | `sum`(기본) · `mean` · `count` · `max` · `min` |
| `-o, --out` | 결과 파일 경로 (기본: `폴더/보고서_YYYYMMDD.xlsx`) |

결과 파일 시트: `요약`(파일별 행 수) · `합친데이터`(맨 앞에 원본파일 열) · `집계`(합계 행 포함) · `중복행`(있을 때만).
이전에 만든 `보고서_*.xlsx`와 엑셀 임시파일(`~$`)은 자동으로 제외합니다. 파일 하나를 읽지 못해도 나머지는 계속 처리하고 요약 시트에 실패 사유를 남깁니다.
