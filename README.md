# JY 업무노트

일정 기록 · 회의 메모 · 자동 요약 · 업무 데이터 조회를 한 곳에서 하는 **업무용 웹앱(PWA)** 입니다.
PC 브라우저에서는 홈페이지로, 휴대폰에서는 "홈 화면에 추가"로 **앱처럼 설치**해서 쓸 수 있습니다.

## 주요 기능

| 메뉴 | 기능 |
|---|---|
| 🏠 홈 | 오늘·이번 주 일정, 마감 임박/기한 지난 할일, 최근 회의 요약 한눈에 보기 |
| 📅 일정 | 월간 달력, 날짜 클릭 → 일정 보기, 같은 날짜 한 번 더 클릭 → 바로 추가. 일정에서 바로 회의메모 작성 |
| 📝 회의메모 | 자유 메모 작성 → **요약 / 결정사항 / 할일 / 키워드** 자동 정리 후 저장 |
| ✅ 할일 | 회의에서 나온 할일이 자동 등록됨. 담당자·기한·완료 관리 |
| 🔎 조회 | 빠른 리포트(이번 주 일정, 미완료 할일, 이번 달 회의 요약, 최근 결정사항), 키워드·기간 검색, **결과 엑셀 저장**, **AI에게 질문** |
| ⚙️ 설정 | 전체 엑셀 내보내기/가져오기, JSON 백업·복원, AI 설정, 예시 데이터 |

### 요약 방식 2가지
- **⚡ 자동 요약 (무료, 오프라인)**: 기기 안에서 바로 동작합니다.
  - `결정`, `확정`, `합의`, `승인` → 결정사항
  - `@이름`, `담당`, `~까지`, `요청`, `예정` → 할일 (담당자·마감일 자동 인식: `11/20`, `2026-11-20`, `내일`, `다음 주` 등)
- **✨ AI 요약 (선택)**: 설정에 Claude API 키를 넣으면 Claude가 문맥을 이해해 더 정확하게 요약합니다.
  같은 키로 조회 탭의 **AI에게 물어보기**("지난달 A프로젝트 결정사항 정리해줘")도 사용할 수 있습니다.

## 갤럭시 탭 S8 + S펜 사용법

- **화면**: 가로 모드는 왼쪽 메뉴 + 넓은 화면, 세로 모드는 아이콘 메뉴로 자동 전환됩니다. 버튼은 손가락으로 누르기 쉽게 크게 조정되어 있습니다.
- **회의메모 = 노란 줄노트**: 회의메모를 열면 전체 화면 노트가 뜹니다.
  - **✍️ 펜 필기**: S펜으로 바로 쓰기 (필압 반영). 펜 / 형광펜 / 지우개, 색상·굵기, 실행취소·다시실행
  - **S펜 측면 버튼을 누른 채 문지르면 지우개**
  - **손바닥 인식 방지**: S펜을 한 번 쓰면 그 뒤로 손가락은 스크롤만 합니다. (펜이 없으면 ☝️ 손가락 버튼으로 손가락 필기 켜기)
  - 페이지 끝까지 쓰면 다음 쪽이 자동으로 추가됩니다.
  - **⌨️ 텍스트**: 키보드 입력도 같은 줄노트 디자인
  - 가로 모드에서는 오른쪽에 요약 패널이 항상 보이고, 세로 모드에서는 **📋 요약** 탭으로 이동합니다.
- **필기 인식 (AI)**: “필기 텍스트 변환”을 누르면 손글씨를 텍스트로 옮겨 검색·엑셀에 활용할 수 있습니다. “AI 요약”은 필기와 텍스트를 함께 읽고 요약합니다. (Claude API 키 필요, 필기 원본은 그대로 보관)
- **앱 설치**: 탭에서 Chrome 또는 삼성 인터넷으로 주소를 열고 메뉴 → **홈 화면에 추가 / 앱 설치**

## 탭·PC 동기화 설정 (처음 한 번, 약 10분)

구글 계정으로 로그인하면 탭과 PC가 같은 기록을 봅니다. 사이트 주소가 공개여도 **로그인한 본인만 자기 기록을 볼 수 있습니다** (`firestore.rules` 보안 규칙).
무료 요금제(Spark)로 개인 업무 기록은 충분합니다.

1. https://console.firebase.google.com 접속 → **프로젝트 만들기** (이름 예: `jy-work`, Google 애널리틱스는 꺼도 됨)
2. 왼쪽 **빌드 → Authentication → 시작하기** → 로그인 방법에서 **Google** 사용 설정 → 저장
3. **Authentication → 설정 → 승인된 도메인 → 도메인 추가**: `jyseong0402-design.github.io`
4. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
5. Firestore의 **규칙** 탭 → 내용을 모두 지우고 이 저장소의 `firestore.rules` 내용을 붙여넣기 → **게시**
6. 프로젝트 설정(⚙️) → **내 앱 → 웹 앱 추가(`</>`)** → 앱 닉네임 입력 → 나오는 `firebaseConfig = { ... }` 복사
7. 업무노트 앱 **설정 → 탭·PC 동기화 → Firebase 연결 설정**에 붙여넣고 저장 → **구글 계정으로 로그인**
8. 탭과 PC 각각 같은 구글 계정으로 로그인하면 끝

> 6번의 설정값을 `js/firebase-config.js`에 넣어두면 기기마다 붙여넣지 않아도 됩니다. (설정값은 비밀번호가 아닌 공개 식별자입니다)
> 로그인 전에 기기에 쓴 기록도 로그인하면 자동으로 올라갑니다. 같은 항목을 두 기기에서 고치면 나중에 고친 내용이 남습니다.
> 설치한 앱에서 로그인 창이 열리지 않으면, 같은 주소를 크롬(브라우저)으로 열어 한 번 로그인하세요.

## 실행 방법

정적 파일만으로 동작하므로 서버 프로그램이 필요 없습니다.

**PC에서 바로 테스트**
```bash
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속

**인터넷 주소로 공개 (휴대폰 앱으로 쓰기)** — GitHub Pages 추천
1. GitHub 저장소 → Settings → Pages
2. Source: `Deploy from a branch`, Branch: `main` / `(root)` 선택 후 저장
3. 1~2분 뒤 표시되는 주소(`https://<아이디>.github.io/<저장소명>/`)로 접속
4. 휴대폰에서 해당 주소 열기 → 공유(iPhone) / 메뉴(Android) → **홈 화면에 추가**

## 데이터 저장 위치 (중요)
- 기록은 먼저 **사용하는 기기의 브라우저**에 저장되고(필기는 IndexedDB), **동기화 로그인 시 내 Firebase 계정(클라우드)에도 저장**됩니다.
- 로그인하지 않으면 기기마다 기록이 따로 있습니다. 서버로 전송되지 않습니다.
- PC와 휴대폰은 데이터가 따로 저장됩니다. 옮길 때는 **설정 → 엑셀 내보내기/가져오기** 또는 **백업 파일(JSON)** 을 사용하세요. (펜 필기는 백업 파일에만 포함되고, 엑셀에는 쪽수만 기록됩니다)
- 브라우저 데이터 삭제 시 기록도 지워지므로 **주기적으로 엑셀/백업 저장**을 권장합니다.
- AI 사용 시에만 해당 메모/기록이 Anthropic API로 전송되며, API 키는 이 기기 브라우저에만 저장됩니다.

## 엑셀 형식
내보낸 파일은 `일정`, `회의메모`, `할일` 3개 시트로 구성됩니다. 엑셀에서 수정 후 다시 가져오면
같은 `ID` 행은 갱신되고, `ID`가 비어 있는 행은 새로 추가됩니다. (회의메모 `할일` 열 형식: `내용 / 담당 / 마감일`, 한 줄에 하나)

## 파일 구성
```
index.html              화면
css/style.css           디자인 (PC·모바일 반응형, 다크모드)
js/app.js               화면 동작
js/store.js             데이터 저장
js/summarize.js         오프라인 자동 요약
js/ai.js                Claude AI 요약·질문
js/excel.js             엑셀 내보내기/가져오기
js/ink.js               S펜 필기 엔진 (필압, 지우개, 손바닥 인식 방지)
js/inkdb.js             필기 데이터 저장 (IndexedDB)
js/sync.js              탭·PC 동기화 (구글 로그인 + Firestore)
js/firebase-config.js   Firebase 연결 설정(선택)
firestore.rules         Firestore 보안 규칙 (본인만 접근)
js/vendor/              SheetJS(엑셀), Anthropic SDK (오프라인 동작용 포함)
manifest.webmanifest    앱 설치 정보
sw.js                   오프라인 캐시
```
