📋 월마감 현황

내가 만들 파일과 필요한 파일·생산자를 관리하고, 이번 달에 받은 파일과 완성한 파일을 체크합니다. 번호는 이 사이트의 순서(⠿ 끌어서 변경)이고, 자동화된 업무는 📊 파일 생성으로 바로 만들 수 있습니다.

목록은 내 계정에 저장되고, 📄 양식 파일은 이 기기 브라우저에만 보관됩니다 (서버로 보내지 않음).

📈 KPI 현황

KPI 엑셀을 불러오면 Summary 시트의 월별 실적·예산으로 요약, 그래프, 특이사항, 전월 비교를 보여줍니다. 매달 새 KPI 파일을 다시 불러오면 갱신됩니다.

📥 RD 보관함

이번 달 RD를 한 번 올려 두면, 만들 수 있는 월마감 자료를 한꺼번에 만듭니다. 파일은 이 기기 안에만 월별로 보관됩니다 (외부 서버·요금 없음).

📂 RD 파일을 끌어다 놓거나 눌러서 선택 거래처원장 · 계정별원장 · 기간별입고현황 · 운반비 집계파일 (전체계정 그대로, 여러 개 가능) — 종류는 자동으로 알아봅니다

올려 둔 RD

이 RD로 만들 수 있는 자료

처음 한 번은 자료마다 '지난달 파일 넣기'로 지난달 완성본을 넣어 주세요. 그 뒤로는 만든 파일이 자동으로 다음 달의 지난달 파일이 됩니다.
⚠ 거래처원장은 지난달과 같은 법인 범위로 받아 주세요. 만들 때 이번 RD의 기초 잔액을 지난달 잔액과 대조해서, 다르면 경고합니다.

💬 RD에 물어보기

원하는 데이터를 말로 요청하면, 보관함 RD에서 골라 원래 ERP 양식(같은 열·머리글)으로 표와 엑셀을 만듭니다. 계정 이름(예: 제조 전력비)·법인·잔액 조건은 API 키 없이도 바로 해석하고, 설정에 Claude API 키가 있으면 더 자유롭게 물어볼 수 있습니다. 금액은 이 PC 밖으로 나가지 않습니다.

📊 자료생성

만들 자료를 고르고 필요한 파일을 넣으면, 기존 양식·수식은 그대로 두고 이번 달만 붙인 엑셀이 만들어집니다. 파일은 이 기기 안에서만 처리됩니다.

① 운반비 집계파일타부서에서 받은 파일 ('현황' 시트)
② ERP 계정별원장전체계정 원장 그대로 OK · 회사별로 여러 개
③ 지난 검증파일지난달까지 작업한 검증파일
검증 규칙 보기
  • 원장: 운반보관비 3개 계정(선행·후행·기타)만, 차변만 사용 (결산전표 등 대변 행 제외)
  • 오아시스 후행물류비 차감(차변 음수)은 매출차감 항목이라 0원 처리
  • 운반비N월 시트는 지난달 시트를 그대로 복사하고, 납품처 금액(H열)만 집계파일 '현황' Total 값으로 바꿈 (회사·납품처·운송사 이름으로 맞춤)
  • 운송사·납품처 이름이 바뀐 행은 그 자리에서 고치고, 새 납품처는 빈 행에 추가 — 화면에 목록으로 알려줌
  • 차이 나는 지급처는 U열 사유에 '제안)'으로 지난달 사유·원장 적요를 적어 둠
  • 같은 달을 다시 만들면 그 달 시트·원장 행을 새로 바꿈

    🔄 탭·PC 동기화

    구글 계정으로 로그인하면 갤럭시 탭과 PC에서 같은 기록(일정·회의메모·펜 필기·할일)을 볼 수 있습니다. 인터넷이 끊겨도 기기에 먼저 저장되고, 연결되면 자동으로 맞춰집니다. 내 계정으로 로그인한 사람만 내 기록을 볼 수 있습니다.

    Firebase 연결 설정 (처음 한 번)

    Firebase 콘솔 → 프로젝트 설정 → 내 앱(웹)의 firebaseConfig 내용을 그대로 붙여넣고 저장하세요. 자세한 방법은 README의 “탭·PC 동기화 설정”을 참고하세요.

    ✍️ 필기 점검·복구

    필기가 있다고 표시된 메모마다 이 기기·이전 판·클라우드에 실제로 남은 필기(획 수)를 보여 줍니다. 비어 보이는 메모가 있으면 눌러 보세요 — 남아 있는 쪽이 있으면 그 내용으로 되돌릴 수 있습니다.

    엑셀

    일정·회의메모·할일이 시트별로 저장됩니다. 엑셀에서 수정한 뒤 다시 가져올 수 있습니다(같은 ID는 덮어쓰기).

    AI 요약 (선택)

    API 키가 없으면 기기 안에서 동작하는 자동 요약을 사용합니다. Claude API 키를 넣으면 더 정확한 AI 요약과 AI 질문을 쓸 수 있습니다. 키는 이 기기의 브라우저에만 저장됩니다.

    백업 · 복원

    데이터는 이 기기(브라우저)에 저장됩니다. 다른 기기로 옮기거나 보관하려면 백업 파일을 저장하세요.
